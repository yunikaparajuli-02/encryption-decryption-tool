# Message Encyption and Decryption Tool

## Project Description
This project was developed as part of the Introduction to Programming coursework.
It allows users to encrypt and decrypt text messages using a key-based encryption technique.

## Features 
- Encrrypt messages using a secret key 
- Decrypt an encrypted message 
- Command-line based interaction 
- Input validation for better safety
- User-friendly instructions 

## How to Run 
1. Open terminal 
2. Navigate to project folder 
3. Run the program:
python3 encryption_tool.py

## Example 
Message : HELLO
key : KEY
Output : Encrypted message displayed 

## Testing 
The program was tested using different message and keys.
Encryption and decryption were successfully verified.
